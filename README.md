# «Айсберг» — сайт-визитка климатической компании

Готовый статический сайт: чистый HTML + CSS + Vanilla JS, без сборки, фреймворков и внешних библиотек. Работает офлайн (кроме отправки формы в Formspree).

- Главная: установка и обслуживание, слайдер работ, CTA-блок, форма заявки.
- Каталог: карточки товаров из JS-массива, фильтры, поиск, сортировка.
- Служебная страница с шаблоном политики конфиденциальности.

## Быстрый старт

Сайт уже поднят в DSH:

**http://127.0.0.1:5500/**

Если сервер нужно запустить заново (из папки проекта):

```powershell
python -m http.server 5500
```

Или откройте папку в VS Code и нажмите **Go Live** (Live Server). Открывать `index.html` двойным кликом тоже можно, но для проверки Formspree лучше использовать локальный сервер: браузеры ограничивают запросы с `file://`.

## 1. Formspree — подключение формы

Форма находится на главной в секции `#contact` и отправляется через Formspree без перезагрузки страницы.

1. Зарегистрируйтесь на [formspree.io](https://formspree.io/) и создайте форму.
2. Скопируйте endpoint вида `https://formspree.io/f/abcdwxyz`.
3. Откройте `js/config.js` и вставьте его:

```js
window.SITE_CONFIG = {
  formspreeEndpoint: "https://formspree.io/f/abcdwxyz",
  requestTimeout: 15000
};
```

Можно вставить и один ID — `abcdwxyz`; скрипт сам соберёт URL.

Пока значение пустое, сайт работает в **демо-режиме**: валидация и плашка успеха работают, но заявка никуда не отправляется, а под формой виден жёлтый блок с подсказкой. После вставки endpoint блок исчезает, а форма делает реальный POST-запрос.

Что отправляется в Formspree:

| Поле | Значение |
|---|---|
| `name` | Имя |
| `phone` | Телефон в формате `+7 (999) 123-45-67` |
| `comment` | Комментарий (необязательно) |
| `consent` | Согласие на обработку данных (`on`) |
| `product` | Модель, если заявка пришла из каталога |
| `_subject` | Тема письма |
| `_gotcha` | Скрытая ловушка для спам-ботов |

Дополнительно в коде уже есть:

- маска телефона и понятные ошибки под полями;
- проверка имени и обязательного согласия;
- блокировка кнопки и спиннер во время отправки;
- таймаут запроса (15 секунд);
- всплывающая плашка успеха и ошибки с автозакрытием;
- предзаполнение комментария при переходе из каталога: `index.html?product=daikin-ftxb25c#contact`.

> Endpoint Formspree виден в исходниках страницы — это нормально для статических сайтов. Не храните в нём секретные ключи.

## 2. Каталог — как добавить или убрать товар

Все товары лежат в `js/products.js` в массиве `window.PRODUCTS`. Карточки, фильтры и поиск обновляются автоматически.

Минимальный товар:

```js
{
  id: "my-model",                        // уникальный латинский id
  brand: "Daikin",
  name: "FTXB25C",
  description: "Тихая сплит-система для спальни",
  price: 32900,                          // целое число, рубли
  oldPrice: 36900,                       // необязательно
  category: "wall",                      // wall | multi | mobile
  tags: ["inverter", "wifi"],            // inverter включает фильтр
  specs: ["до 25 м²", "2,5 кВт", "Wi-Fi"],
  badge: { text: "Хит продаж", type: "hit" }, // hit | sale | new
  image: "images/products/my-model.jpg",
  imageAlt: "Кондиционер Daikin FTXB25C",
  popular: 100                           // для сортировки «Сначала популярные»
}
```

- Цена выводится как «от 32 900 ₽»; форматирование делает `Intl.NumberFormat`.
- Чтобы убрать товар — удалите объект из массива.
- Фото: 1200 × 900 px, положите в `images/products/`. Временно можно оставить заглушку.
- Фильтр «Инверторные» показывает товары с тегом `inverter`.
- Фильтр «Настенные» — `category: "wall"`, «Мульти-сплит» — `"multi"`, «Мобильные» — `"mobile"`.
- Порядок по умолчанию — по убыванию `popular`.

## 3. CTA-блок — отредактировать или удалить

На главной между слайдером работ и секцией «Почему мы» есть тёмный блок «Установим кондиционер за один день».

В `index.html` он обёрнут заметными комментариями:

```html
<!-- CTA: начало -->
...текст, кнопка, телефон...
<!-- CTA: конец -->
```

- Меняйте заголовок, описание, текст кнопки и ссылку прямо в этом фрагменте.
- Чтобы полностью убрать блок, удалите всё между комментариями `CTA: начало` и `CTA: конец` включительно. Соседние секции не сломаются.
- Кнопка ведёт на форму `href="#contact"`.

## 4. Фотографии работ

Слайдер на главной берёт файлы:

```text
images/works/work-1.jpg
images/works/work-2.jpg
...
images/works/work-6.jpg
```

Просто замените их своими фото **с теми же именами** — код менять не нужно. Рекомендуемый размер 1600 × 1000 px (16:10), JPG. Подписи к слайдам и alt-тексты находятся в `index.html` (секция `#works`). Чтобы добавить слайд, скопируйте `<figure class="work-slide">…</figure>`; точки и счётчик создаются JS автоматически.

Сейчас в папке лежат сгенерированные заглушки с подсказкой «Фото работы N — замените work-N.jpg». Их можно перегенерировать:

```powershell
python tools/make_placeholders.py
```

## 6. Политика конфиденциальности

`privacy.html` — **шаблон**, а не готовый юридический документ. Замените реквизиты, проверьте текст юристом и опишите реальные сервисы, которые используете (Formspree, аналитика, cookies). Ссылка на политику уже стоит в форме и подвале.

## 7. Дизайн и адаптивность

Палитра, радиусы, тени и шрифты собраны в `:root` в начале `css/style.css`:

```css
--blue-700: #0866c6;
--blue-600: #0b7be0;
--cyan-400: #3dd6f5;
--ice-50:   #f7fbfe;
--grad: linear-gradient(115deg, #2acbf2 0%, #0e8bef 48%, #0b63d6 100%);
```

- Шрифты системные (`Segoe UI` / `Inter` / системный стек), поэтому сайт не зависит от Google Fonts и работает офлайн.
- Проверены ширины 1440, 1024, 768, 390 и 320 px: горизонтального скролла нет.
- Мобильное меню закрывается по Escape и блокирует прокрутку страницы.
- Слайдер поддерживает стрелки, точки, свайп, клавиатуру ← →, автопрокрутку с паузой при наведении/фокусе и отключение при `prefers-reduced-motion`.
- У формы есть `label`, `aria-invalid`, `aria-describedby`, у тоста — `role="status"`.
- Все изображения с `width`/`height` и `alt`; слайды и товары подгружаются лениво.

## 8. Проверки

Синтаксис JS:

```powershell
node --check js/script.js
node --check js/catalog.js
node --check js/products.js
node --check js/config.js
```

Статические проверки (ссылки, id, SVG-символы, поля каталога, классы):

```powershell
python tools/check_static.py
```

Браузерная проверка через headless Chrome (нужен Chrome с `--remote-debugging-port=9222` и запущенный сервер на 5500):

```powershell
node tools/visual-check.mjs
```

Скрипт проверяет консоль, сетевые ошибки, горизонтальный скролл, меню, слайдер, фильтры/поиск/сортировку, пустой результат, предзаполнение формы, валидацию, маску телефона и демо-отправку. Скриншоты складываются в `tools/screenshots/` (это артефакты проверки, для продакшена их можно удалить).

Отдельная проверка реальной отправки в Formspree (подменяет endpoint в браузере и перехватывает POST, файлы проекта не меняются):

```powershell
node tools/test-formspree.mjs
```

Результат последнего прогона: **ошибок нет**; проверены 1440, 1024, 768, 390 и 320 px, а также реальный POST-запрос со всеми полями формы.

## 9. Публикация

Сайт статический — подойдёт GitHub Pages, Netlify, Vercel, Cloudflare Pages или обычный хостинг. Загрузите файлы проекта (папку `tools` можно не загружать), включите HTTPS и проверьте отправку формы уже на боевом домене. Если Formspree ограничивает домены — добавьте свой домен в настройках формы.

---

Если нужно, поменяйте логотип и фирменные цвета: логотип — inline SVG в шапке/подвале, палитра — переменные в `css/style.css`.
